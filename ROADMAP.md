# Roadmap

The roadmap keeps repository claims aligned with committed, reviewable work. Counts describe real local artifacts rather than future promises.

## Phase 1 — Foundation inherited from Flaq AI

- [x] Define a 24-category, production-oriented information architecture;
- [x] Retain all 84 upstream-authored prompt recipes;
- [x] Add twelve reusable templates and an H3-specific prompting guide;
- [x] Add eight README language entry pages and eight localized prompt examples;
- [x] Retain eleven upstream gallery images and add one VideoWeb cover, with image briefs and production records;
- [x] Add contribution, originality, issue, pull-request, asset, and source policies;
- [x] Link H3 capability claims, open weights, and developer resources to official MiniMax locations.
- [x] Document local H3-Base deployment and the hosted/local hybrid 2K workflow in nine languages;
- [x] Curate official H3 example media through attributed upstream links without duplicating source files.

## Phase 2 — Tested examples

- [ ] Test at least one recipe in every category using a documented H3 workflow;
- [ ] Record exact model/tool, reference assets, settings, date, edits, and known defects;
- [x] Add attributed official H3 skill previews and reproducible video links;
- [ ] Add lightweight poster frames and rights-cleared videos generated from this repository's own recipes;
- [ ] Compare text-only, image-guided, video-guided, and audio-guided versions where supported;
- [x] Add automated Markdown link, ID, count, and asset checks via `scripts/check_content.py`.

## Phase 3 — Production depth

- [x] Expand high-value categories with original editing, continuation, camera-transfer, motion-graphics, practical-surreal, vertical-series, live-creator, dialogue, and ensemble recipes;
- [ ] Add precise-edit before/after records for identity, product, UI, sound, and timing changes;
- [ ] Add accessibility, subtitle, disclosure, and localization delivery playbooks;
- [ ] Track H3 interface/API differences without duplicating creative recipes;
- [ ] Promote localized samples to full canonical editions only with native-speaker maintenance.

## Phase 4 — Ongoing quality

- [ ] Periodically verify official H3 capability and integration links;
- [ ] Retest high-value recipes after material model changes;
- [ ] Archive obsolete configuration while preserving creative history;
- [ ] Publish repository metrics from committed, auditable data only.
