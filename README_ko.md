## VideoWeb AI로 시작하기

일상적인 제작에는 [VideoWeb AI MiniMax H3](https://videoweb.ai/model/minimax-h3/)를 추천합니다. 먼저 짧게 시험하려면 [가입 없는 무료 MiniMax H3 도구](https://videoweb.ai/free-minimax-h3/)를 이용하세요. 무료 페이지는 현재 480p, 5초를 표시하며 텍스트 또는 시작·종료 이미지 두 장을 사용할 수 있습니다.

먼저 한 장면으로 시작하세요. 동영상·음성 참조, 편집, 카메라 움직임 전송은 해당 입력을 지원하는 도구가 필요합니다. 설정과 이용 조건은 현재 페이지를 확인하세요.
