## By workflow stage

| Stage | Recommended practice |
|---|---|
| Brief | Define the audience, channel, duration target, outcome and rights boundary |
| Reference map | Give each image, video and audio input one explicit role and a conflict priority |
| Structure pass | Validate subject, action, camera, beat order and ending before polish |
| Control pass | Lock identity, product, wardrobe, geography, UI, props and screen direction |
| Precision edit | Change one target only; repeat every invariant in the revision prompt |
| Localization | Translate the full specification and review culture, direction, copy and sound |
| Delivery | Verify facts, claims, text, rights, disclosure, codec, crop, thumbnail and playback |
