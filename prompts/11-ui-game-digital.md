## DIG-001 Focus Timer Product Walkthrough

**Status:** Concept — not independently tested

**Use it for:** A clean landing-page motion demo of a productivity feature with realistic states.

**Mode:** UI screens + interaction map + optional cursor motion reference  
**Format:** 16:9, target 12 seconds  
**Reference map:** Images 1–3 = exact desktop UI states; Image 4 = interaction order; Video 1 = cursor speed only.

```text
Create a polished product walkthrough for the fictional desktop focus timer “QUIET HOUR”. Reproduce only the approved UI in Images 1–3: charcoal window, cream timer card, green progress ring, task list, pause control. Preserve all supplied text exactly; do not invent metrics, testimonials, or menu items.

Start on the idle state. Cursor moves at the natural speed of Video 1, selects one task, and presses Start. Transition to the running state with a 250ms ease: timer begins, progress ring advances slightly, task row gains a restrained green indicator. A small notification slides in once, the user activates “Silence alerts,” and the notification collapses. Finish by zooming out to show the same app on a realistic laptop screen with safe copy space beside it.

Use crisp UI, no perspective distortion during interaction, and subtle screen reflections only in the final hardware shot. Sound intent: two soft clicks and one muted chime. Avoid unreadable microtext, invented charts, random hover effects, cursor teleporting, extra windows, brand logos, or watermark.
```

**Review:** Exact UI states, text fidelity, interaction causality, cursor path, and practical motion timing.

**Mode:** Dashboard image + handlebar image + state diagram  
**Format:** 4:5, target 8 seconds  
**Reference map:** Image 1 = exact display; Image 2 = handlebar/control positions; Image 3 = approved three-state flow.

```text

```

**Review:** Button-state mapping, label accuracy, hardware geometry, accessibility contrast, and safe stationary context.
